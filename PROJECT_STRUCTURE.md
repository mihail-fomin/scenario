## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Dev-сервер Vite (порт 3001) |
| `npm run build` | Проверка типов и production-сборка |
| `npm run type-check` | Только проверка типов |
| `npm run lint` / `lint:fix` | ESLint |
| `npm test` | Тесты (vitest) |
| `npm run check` | Типы + линтер + тесты |

Режим отладки ассетов: `http://localhost:3001/?asset-debug` (только в dev).

## Поток данных

1. **App** создаёт персонажей, `StageManager`, `CameraDirector` и подключает UI.
2. При запуске диалога `StageManager` ведёт персонажей на место действия, `TimeOfDay` плавно меняет время суток, `CameraDirector` сопровождает прогулку.
3. На каждой реплике `emotion.ts` определяет настроение: меняются лица, жесты и реакции слушателей, а режиссёр выбирает план (крупный, средний, через плечо, двойной, общий).
4. Каждый кадр: режиссёр задаёт кадр → `SceneManager.update` обновляет персонажей, время суток, декор и камеру. `CameraController` плавно догоняет желаемое положение (сглаживание не зависит от FPS), а пользователь может в любой момент перехватить камеру мышью.

## Что покрыто тестами

Чистая логика без WebGL: определение эмоций, согласованность диалогов с персонажами и местами, расстановка персонажей (`StageManager`), выбор планов (`CameraDirector`), пересчёт UV и ночной режим окон. Графику (`TimeOfDay`, текстуры, `SceneManager`) проверяют визуально.
