# 3D Диалог Персонажей

Интерактивная 3D сцена: трое друзей во дворе вспоминают истории, ходят по двору, жестикулируют и меняют выражение лиц, а камера снимает разговор как оператор. Субтитры и озвучка на русском.

## Возможности

- 🎭 Персонажи с лицом, мимикой, походкой, жестами и эмоциями (по тексту реплики)
- 📍 Для каждой темы персонажи идут в «своё» место двора; время суток подстраивается под сюжет
- 🎥 Камера-оператор: крупный, средний, «через плечо», двойной и общий планы; свободное управление мышью/касанием с плавным возвратом
- 🌅 Время суток: небо, солнце, луна, звёзды, туман, ночное освещение окон и фонарей
- 🧱 Процедурные текстуры, тени, декор двора, жители (бабушки, дети, прохожие)
- 👆 Клики по объектам сцены (карусель, мяч, машины, персонажи)
- 🔊 Text-to-Speech и процедурный звук двора (включается кнопкой)
- 📱 Адаптивный интерфейс

## Технологии

TypeScript, Vite, Three.js, Web Speech API / Web Audio, ESLint (typescript-eslint), Vitest.

## Установка и запуск

```bash
npm install
npm run dev      # http://localhost:3001
```

## Разработка

| Команда | Что делает |
|---|---|
| `npm run check` | Типы + линтер + тесты (запускайте перед коммитом) |
| `npm run type-check` | Проверка типов TypeScript |
| `npm run lint` / `npm run lint:fix` | ESLint |
| `npm test` / `npm run test:watch` | Тесты (vitest) |
| `npm run build` | Типы + production-сборка в `dist/` |

Режим отладки ассетов (только в dev): `http://localhost:3001/?asset-debug`.
